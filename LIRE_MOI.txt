MES PROJETS — V1

1. Ouvrez index.html dans Chrome ou Edge.
2. Les données sont enregistrées automatiquement dans le navigateur de ce PC.
3. Cliquez sur un projet pour cocher ses étapes ou en ajouter.
4. Le bouton + permet de créer un nouveau projet.
5. La progression est calculée automatiquement à partir des étapes cochées.

Cette V1 est volontairement locale et simple. Ne supprimez pas les données du navigateur si vous voulez conserver votre suivi.
